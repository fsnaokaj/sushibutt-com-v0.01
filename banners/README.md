# /public/banners/

Place full-width hero banner images here.
These are used in the HeroBanner carousel component.

## Naming convention
Campaign banners should match the campaign ID:
  talking-head-ugc-english.jpg
  stockx.jpg
  kitsch.jpg
  cod-mw4.jpg
  ...

## Recommended specs
- Dimensions: 1400 × 520px
- Format: .jpg or .webp
- Max file size: 300KB

Referenced in: src/data/campaigns.ts → bannerUrl field
