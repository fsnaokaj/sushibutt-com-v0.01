# /public/thumbnails/

Place campaign card thumbnail images here.
These appear in the CampaignCard grid and modal.

## Naming convention
Match the campaign ID in src/data/campaigns.ts:
  kitsch.jpg
  stockx.jpg
  cod-mw4.jpg
  ...

## Recommended specs
- Dimensions: 480 × 270px (16:9 ratio)
- Format: .jpg or .webp
- Max file size: 150KB

Referenced in: src/data/campaigns.ts → thumbnailUrl field
